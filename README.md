# Python Port Scanner

## Description

A Python-based Port Scanner that scans a target host and identifies open ports using socket programming.

## Features

- Scan IP addresses and websites
- Detect open ports
- Hostname to IP resolution
- Timeout handling
- Error handling
- Fast scanning of common network ports

## Technologies Used

- Python
- Socket Programming

## Skills Demonstrated

- Networking Fundamentals
- Python Programming
- Socket Programming
- Error Handling
- Cybersecurity Basics

## How to Run

1. Install Python
2. Open terminal
3. Run:

```bash
python port_scanner.py
```

4. Enter a target IP or website

Example:

```text
google.com
```

## Example Output

```text
Scanning target: google.com

Port 80 is OPEN
port 443 is OPEN
Scan completed.
```
